# Общие группы упоминаний — 4.12.11

Группы создаются в **Space Settings → Группы упоминаний**. Наберите `@` и выберите группу в подсказках. Названия поддерживают кириллицу, латиницу, пробелы и скобки; имя `room` и символ `@` зарезервированы. Группа может быть пустой или состоять из одного участника. Состав виден всем участникам пространства. Изменять его могут участники с правом отправки соответствующего state-события пространства (обычно администраторы).

В Cinny группа отображается одной цветной плашкой. Element и другие клиенты получают читаемую подпись группы и обычные ссылки на упомянутых участников. Для уведомлений используется стандартное `m.mentions`: повторяющиеся получатели объединяются, отправитель исключается, `@room` работает независимо. Получатели группы должны состоять и в пространстве, и в текущей комнате; их статус online/offline не влияет на упоминание. Уведомления подчиняются личным настройкам Matrix.

Список групп хранится в state пространства: `in.cinny.mention_group`, отдельный случайный `state_key` для каждой группы, содержимое `{name, color, user_ids}`. Удаление записывает пустой объект. Для работы не требуется менять homeserver. Поскольку это state пространства, определения групп не зашифрованы. Сообщения в зашифрованных комнатах шифруются штатным механизмом Matrix.

При отправке клиент загружает полный состав комнаты и пространства. Сообщение сохраняет снимок получателей: последующее изменение группы не переписывает историю и не меняет адресатов старых упоминаний при редактировании. Скопированная в новое сообщение плашка получает актуальный состав. Изменение текста не пингует прежних адресатов повторно; новые адресаты редактирования передаются отдельно. Кодовые блоки и inline code не вызывают уведомлений.

Группы доступны в комнатах присоединённых пространств и известных клиенту вложенных пространств. Для неизвестного клиенту промежуточного пространства его иерархию сначала необходимо загрузить. Если одна комната находится в нескольких пространствах, подсказки показывают пространство каждой группы.

Размер Matrix-события ограничен. Клиент проверяет размер с запасом, в том числе при шифровании и редактировании. Если текст вместе с раскрытым списком получателей слишком велик, отправка останавливается с объяснением и сохраняет черновик. Получатели не обрезаются молча. Это ограничение особенно существенно для очень больших групп при совместимости с обычными клиентами.

Проверки:

- `npm run test:mentions --prefix cinny`: все 32 сочетания трёх пересекающихся групп, пользователя и `@room`, повторы, пустые/одиночные группы, lazy-loading, история, копирование, иерархия, повреждённая HTML-разметка, Markdown, границы подсказок и размер события.
- `tests/e2e/mention_groups.py`: Chromium, Firefox, WebKit; широкое и узкое окно; отправка, редактирование, удаление, совместное управление и права обычного участника.
- `tests/e2e/mention_groups_crypto_threads.py`: два одновременных редактора, треды, уведомление только группы и обмен в зашифрованной комнате между двумя сеансами.
- `tests/e2e/element_group_compat.py`: фактическое сообщение Cinny в официальном Element и стандартное highlight-уведомление Synapse.

Сквозные проверки используют отдельный локальный Synapse и создают одноразовые тестовые аккаунты. Они не обращаются к рабочим пространствам.

Android APK для локальной проверки подписан отдельным тестовым ключом. Для обновления существующей установки нужен тот же ключ, которым подписана установленная версия. Windows-пакет не имеет Authenticode-подписи. Нативная проверка macOS требует машины macOS; WebKit на Linux её не заменяет.
