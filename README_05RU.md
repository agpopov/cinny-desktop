# Cinny Desktop — корпоративная сборка

Форк [cinny-desktop](https://github.com/cinnyapp/cinny-desktop) v4.12.7 (Tauri 2) и веб-клиента
[cinny](https://github.com/cinnyapp/cinny) v4.12.7 с доработками для работы на Windows.

## Что изменено

### Уведомления Windows
- **Раньше уведомления не приходили вообще.** Cinny создавал их через браузерный `new Notification()`,
  а встроенный в Tauri WebView2 на Windows такие уведомления не показывает.
- Теперь уведомления нативные (WinRT toast), с аватаром отправителя, названием комнаты и текстом.
  Ответ в треде подписан «В треде: …».
- Клик по уведомлению разворачивает окно и открывает нужную комнату, а для ответа в треде — сам тред,
  прокрученный к сообщению.
- Решение «показывать или нет» принимается по push-правилам сервера, поэтому режимы комнат
  («только упоминания», «без звука») работают так же, как в Element.
- Тред беспокоит, только если вы его начали или писали в нём. Упоминание приходит всегда.
- Не показываются: свои сообщения, сообщения в открытой и активной комнате или треде,
  «догонялка» старше 10 минут после сна или разрыва сети.
- Мигание кнопки на панели задач и бейдж с числом непрочитанного (красный — есть упоминания).

### Трей и автозапуск
- Значок в трее меняется: обычный, есть непрочитанное (синяя точка), есть упоминания (красная),
  «Не беспокоить» (серый). В подсказке число непрочитанного.
- Меню трея: открыть, «Не беспокоить» (1 ч / 8 ч / до завтра 9:00 / пока не выключу),
  настройки уведомлений, автозапуск, сворачивание при закрытии, выход.
- Крестик окна по умолчанию сворачивает в трей. Это настраивается.
- Автозапуск с Windows, по умолчанию свёрнутым в трей.
- Повторный запуск ярлыка не открывает вторую копию, а показывает уже открытое окно.

### Звук и «Не беспокоить»
- Громкость звука и кнопка «Проверить».
- Звук только для упоминаний и личных сообщений.
- Опция «Показывать текст сообщения» — для общих экранов.
- Ручной режим «Не беспокоить» с таймером. Можно пропускать упоминания и личные сообщения.
- Тихие часы по расписанию (например, 19:00–09:00) и выходные целиком.

Всё это находится в «Настройки → Notifications».

### Треды как в Discord
- Ответы в тредах больше не попадают в общую ленту: она только для основного разговора.
- Под корневым сообщением плашка «N ответов · кто ответил последним · когда» с отметкой непрочитанного.
- Тред открывается в боковой панели (на узком экране — на весь экран) со своим полем ввода,
  ответами, реакциями, редактированием и вложениями.
- Кнопка «Треды» в шапке комнаты открывает список тредов комнаты (загружается с сервера):
  фильтры «Все» и «Мои», счётчики непрочитанного. На кнопке — число тредов,
  где у вас есть непрочитанное.
- Значок треда на сообщении («Начать тред») открывает новую панель вместо ответа в общем поле.
- Ответы в чужих тредах без упоминаний не подсвечивают комнату в списке.
  «Отметить прочитанным» и Esc отмечают и треды.

Технически включён `threadSupport` в matrix-js-sdk. **При первом запуске новой версии
кэш синхронизации сбрасывается один раз**: клиент заново загрузит комнаты. Ключи шифрования,
вход и настройки не затрагиваются.

### Исправлено попутно
- Два одновременно открытых поля ввода (комната и тред) роняли приложение:
  все редакторы Slate делили один объект начального значения
  (`cinny/src/app/components/editor/Editor.tsx`).
- Автообновление из апстрима выключено (feature `updater` убран из `default`, артефакты
  апдейтера не собираются). Иначе апстрим перезапишет корпоративную сборку.

## Как завести форк в GitLab

1. Создайте два репозитория: `cinny` (форк веб-клиента) и `cinny-desktop`.
2. В `cinny` примените `cinny-05ru.patch` поверх тега `v4.12.7`:
   `git checkout -b corp v4.12.7 && git am cinny-05ru.patch`.
3. В `cinny-desktop` примените `cinny-desktop-05ru.patch` поверх `v4.12.7`.
4. Направьте сабмодуль на свой форк:
   ```
   git config -f .gitmodules submodule.cinny.url https://gitlab.<ваш-домен>/<группа>/cinny.git
   git submodule sync && cd cinny && git fetch && git checkout corp && cd .. && git add .gitmodules cinny
   ```
5. В `config.json` (корень `cinny-desktop`) пропишите свой homeserver, чтобы его не вводить при входе:
   ```json
   "defaultHomeserver": 0,
   "homeserverList": ["matrix.<ваш-домен>"],
   "allowCustomHomeservers": false
   ```

## Сборка

**В CI.** `.gitlab-ci.yml` содержит два задания. `web:check` (Linux, Docker) запускает линтер
и собирает веб-часть. `windows:build` собирает установщики и требует Windows-раннер с тегом
`windows` и установленными Node.js 24, Rust `stable-x86_64-pc-windows-msvc` и Visual Studio
Build Tools (C++). Артефакты: `src-tauri/target/release/bundle/msi/*.msi` и
`src-tauri/target/release/bundle/nsis/*-setup.exe`.

**Локально на Windows:**
```
cd cinny && npm ci && cd ..
npm ci
npm run tauri build
```
Для разработки: `npm run tauri dev`.

## Раскатка
- `.msi` подходит для групповых политик или SCCM. `.exe` (NSIS) ставится без прав администратора.
- Идентификатор приложения остаётся `in.cinny.app`. Поэтому при установке поверх обычного Cinny
  сохраняются вход и данные, а уведомления подписываются как «Cinny».
- Если пользователь запускает приложение без установщика (портативно), имя для уведомлений
  регистрируется само при старте (`HKCU\Software\Classes\AppUserModelId\in.cinny.app`).
- Если уведомления не появляются, проверьте «Параметры Windows → Система → Уведомления → Cinny»
  и режим «Фокусировка внимания»: Windows сама глушит уведомления в этом режиме.

## Требования к серверу
Треды и счётчики по тредам требуют поддержки Matrix 1.4+ (threads API, тредовые отметки
о прочтении). Synapse начиная с 1.70 подходит. На старом сервере треды работают частично:
список тредов может не загрузиться, отображение в ленте при этом работает.

## Проверка
- Rust-часть проверена компиляцией под `x86_64-pc-windows-msvc` (debug и release).
- Веб-часть: TypeScript без новых ошибок относительно апстрима, ESLint без ошибок, `vite build`.
- Сквозной тест `tests/e2e/threads_notifications.py` (25 проверок) на реальном Synapse
  с подменой IPC Tauri. Он проверяет треды, отправку в тред, уведомления (в том числе отсутствие
  уведомлений для чужих тредов), счётчик, DND из трея, клик по уведомлению, список тредов
  и настройки. Запуск: поднимите Synapse на `127.0.0.1:8008` с пользователями `alice` и `bob`
  (пароль `pass123`), раздайте сборку `cinny/dist` через `tests/e2e/spa_server.py`
  с `config.json`, где `homeserverList: ["http://localhost:8008"]`, затем выполните
  `python3 tests/e2e/threads_notifications.py`.
- Нативный показ тоста, трей и автозапуск проверяются только на живой Windows: в CI
  их проверить нельзя.

## Что не входит
- Остальной интерфейс Cinny остаётся на английском. Новые элементы (треды, уведомления,
  трей) — на русском.
- Push-уведомления при закрытом приложении (FCM/APNs) — это задача для мобильных клиентов.
